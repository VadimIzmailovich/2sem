# Подсчет кораблей и метод Гаусса вычисления определителя
_____
## Программа для подсчета количества кораблей на спутниковых снимках

### Описание

Программа обрабатывает спутниковый снимок, выделяет корабли на темном фоне
Этапы обработки:

1. Преобразование RGB -> BW
2. Контрастирование изображения
3. Подсчет количества кораблей

### Алгоритм работы

```c
//1. Преобразование RGB -> BW 
bw = (r + g + b) / 3;

//2. Контрастирование
if(pixel >= 60) pixel = 255;
else pixel = 0;

//3. Подсчет
totalShips = numWhitePixels / 2;
```

## Метод Гаусса
### Описание
Программа получает на вход размер матрицы N*N и элементы матрицы
Вывод значение определителя
### Алгоритм работы
1. Приведение матрицы к треугольному виду элементарными преобразованиями
```c
// Перестановка строк i j с изменением определителя
void transform1(double** matrix, int i, int j, double* det, int matSize)

// Прибавление к строке i строки j, умноженной на factor
void transform2(double** matrix, int i, int j, double factor, int matSize)
```
2. Вычисление определителя как произведения элементов главной диагонали
```c
// Триангуляция и вычисление определителя
void triangulate(double** matrix, int matSize, double* det)
```
